# 06 — Fuentes y gestión bibliográfica

> Se llena en `docs/tesis/privado/06-FUENTES.md`.
> Regla: **se cita mientras se lee, nunca al final.** Reconstruir cincuenta referencias la
> semana antes de entregar es trabajo perdido y es donde aparecen los errores de citación.

---

## 1. Gestor bibliográfico

Usa **Zotero** (gratis, con conector de navegador y complemento para Word/LibreOffice).
Configúralo una vez con el estilo que exija tu instituto —normalmente **APA 7**— y deja de
preocuparte por el formato de las referencias para siempre.

- ☐ Zotero instalado y conector del navegador activo
- ☐ Colección creada para la tesis
- ☐ Estilo de citación configurado: ______
- ☐ Sincronización/respaldo de la biblioteca activo

> Guarda el **PDF** dentro de Zotero, no solo el enlace. Los enlaces se rompen y los sitios
> caen justo cuando los necesitas.

## 2. Dónde buscar

| Fuente | Para qué | Nota |
|---|---|---|
| **Google Scholar** | Barrido general | Exporta la cita directo a Zotero |
| **SciELO** | Literatura latinoamericana | Contexto regional, y en español |
| **Redalyc / Latindex** | Revistas iberoamericanas | Útil para antecedentes locales |
| **Repositorios de universidades ecuatorianas** | Tesis previas | Te dan formato **y** antecedentes locales |
| **IEEE Xplore / ACM DL** | Ingeniería de software | Muchos resúmenes accesibles aunque el texto no |
| **FAO** | Producción pecuaria | Documentos técnicos citables |
| **ISO / INEN** | Normas | La norma se cita; el texto completo se compra |
| **Registro Oficial del Ecuador** | Leyes y reglamentos | Fuente primaria de lo legal |

**Términos de búsqueda que conviene probar** (en inglés rinde mucho más): *precision
livestock farming smallholder*, *offline-first mobile data collection rural*, *farm
management information system adoption*, *eventual consistency mobile sync*, *ICT4D
sustainability agriculture*, *ISO 25010 software quality evaluation*, *requirements
elicitation case study*.

## 3. Criterios para aceptar una fuente

Antes de guardarla, pregunta:

1. **¿Es verificable?** Autor identificable, año, editorial o revista. Un blog sin autor no
   sirve como base teórica (como ejemplo ilustrativo, a veces sí).
2. **¿Es vigente?** Menos de ~5 años para tecnología; para fundamentos, la antigüedad no
   importa (se cita la fuente original, no una reseña).
3. **¿La leíste?** **No cites lo que no leíste.** El tribunal pregunta, y se nota.
4. **¿La vas a usar?** Una referencia que no aparece en el cuerpo del texto no va en la
   bibliografía.

## 4. Fichas de lectura

Por cada fuente relevante, una ficha. Diez minutos ahora te ahorran una relectura completa
dentro de tres meses.

```
### [Clave de cita, ej. Perez2023]
- **Referencia completa (APA 7):**
- **Tipo:** ☐ artículo ☐ tesis ☐ libro ☐ norma ☐ informe técnico
- **Qué dice (3 líneas):**
- **Qué midió / cómo:**
- **Hueco que deja (lo que tu trabajo llena):**
- **Dónde lo uso:** ☐ Cap. I ☐ Cap. II ☐ Cap. III ☐ Cap. V
- **Cita textual guardada (con página):**
```

## 6. Antiplagio: cómo no tener problemas

- Cita **todo** lo que no es tuyo, incluso parafraseado. Parafrasear sin citar sigue siendo
  plagio.
- Cita textual: entre comillas y con página. Más de 40 palabras: bloque con sangría.
- **Tu propia documentación del repositorio también se cita.** Es una fuente, y reutilizar
  texto propio sin declararlo es autoplagio.
- **Texto generado por IA:** no lo pegues como si fuera redacción tuya. Además del riesgo
  académico, los detectores lo marcan. Úsalo para ordenar ideas y después escribe tú. Si tu
  instituto tiene norma sobre uso de IA, cúmplela y decláralo.
- Corre el antiplagio sobre un borrador **antes** del oficial. Si sale alto, casi siempre es
  por citas mal formateadas, no por plagio real — pero hay que verlo con tiempo.
